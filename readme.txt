                                                                                  🛒 Grocery Management System (Python Mini Project)

 About the Project:

This is a simple Grocery Management System built using Python.
It is a beginner-friendly project to practice OOP, Dictionary, Loop, File Handling, and Exception Handling.

This project helps to manage grocery products like adding, updating, viewing, and deleting items while saving data in a file.


🎯 Purpose

I created this project while learning Python to:

. Improve my programming logic
. Practice OOP (Object-Oriented Programming)
. Understand file handling without using databases
. Build real-world mini project experience


⚙️ Features
➕ Add Product
Add new grocery items
Store price and quantity

👁️ View Products
Display all available products

✏️ Update Product
Update price and quantity of existing products
❌ Delete Product

Remove product from system
💾 Data Storage
All data is saved in a .txt file
Data is loaded automatically when program starts
🗂️ File Structure
grocery_data.txt   → Stores product data
main.py   
→ Main Python program
📥 Input Example
Add Product:
Enter product name: Rice
Enter price: 60
Enter quantity: 10

📊 Data Format in File
Rice,60,10
Milk,120,5
Sugar,90,8
